# Data Structures

This repository contains Python implementations of fundamental data structures, with a focus on singly linked lists. It includes source code, usage examples, and automated tests using `pytest`.

## Features

- **Singly Linked List**
  - Insert at beginning
  - Insert at end
  - Insert at specific position
  - Insert multiple values
  - Remove by index
  - Remove by value
  - Get length
  - Print list

## Getting Started

### Requirements

- Python 3.13
- [pytest](https://pytest.org/) for running tests

### Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/data-structures.git
cd data-structures
```

(Optional) Create and activate a virtual environment:

```bash
python -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install pytest
```

### Running Tests

Execute all tests with:

```bash
pytest
```
